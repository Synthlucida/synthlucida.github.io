FAQ

What people usually ask

Is WEBZENith really free?

Yes. Building a site, the form, the live preview and downloading the finished website are all free with no time limit. There's an optional Gumroad support option that removes the SYNTHLUCIDA footer link and the break-reminder popup during editing — it doesn't affect the core functionality.

Do I need to know how to code?

No. The whole site is built through a form, and the generator produces the finished HTML file for you.

Where do I upload the finished website?

You can upload the downloaded file (or files, if you have extra pages) to any static-site hosting — GitHub Pages, Netlify, or a regular web host.

Can it generate more than one page?

Yes. Besides the main page, you can add any number of custom pages, each with its own title, description and URL — which also helps with SEO.

Can the website be installed as an app?

Yes, optionally. The generator can create a manifest.json and a service worker, so visitors can install the page to their home screen or desktop.

What if I can't finish the site in one sitting?

The app continuously saves your work-in-progress in the browser, and you can also download the project as a file and reopen it later, even on a different computer.
